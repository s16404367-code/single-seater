# Architecture
Coordinates: world X/Z horizontal, Y vertical; heading 0 points +Z, positive heading turns toward +X. SI units: m, s, kg, N, rad, W, J; HUD converts m/s to km/h. Fixed 120 Hz simulation; max frame backlog capped to avoid focus-return explosions. Input, simulation, race control, renderer, audio and UI are separate modules. Track is a closed sampled centerline with estimated widths; projection is shared by surfaces, boundaries, lap timing and AI. Player motion is free-world, never spline-constrained.

No network during gameplay. Build dependencies are installed at build time; static output contains required runtime resources. Preferences and race records remain in browser storage. No external fonts, images or tracking.

AI uses pure-pursuit steering and curvature/braking look-ahead, with skill-dependent lateral-acceleration targets/reaction/consistency. No position scripting. Local line choices for passing/defending; stuck recovery reverses through physics. Car contacts use two equal-mass overlapping circles, three positional-separation iterations and low restitution. LapTimer stores common unwrapped progress, ordered sector gates and bounded crossing history for time gaps. Reset invalidates best lap; race classification follows completed laps/progress. Starts are physically locked until lights out (false starts currently not supported).

## Phase 3 force model
800kg, yaw inertia 1450 kg m²; wheelbase 3.3m, center of mass 0.32m above road; tire radius .38m. Force-based planar bicycle with four load/force/temperature/wear records, tanh lateral force curve, combined friction-circle saturation and algebraic load transfer. World velocity is integrated from forces; yaw from axle moments. There is no fully simulated suspension, wheel angular momentum, tire carcass, exact longitudinal slip ratio or proprietary tire calibration. `slipDemand` is explicitly a force-demand saturation proxy, not a measured wheel slip ratio. Low-speed reverse uses a documented kinematic yaw blend to avoid singularities. Default traction assist reserves rear lateral grip before applying drive force; no unlimited cornering grip.
Aero uses .5*rho*v²*C*A, rho=1.225, A=1.5m². DRS (hold F) is eligible above25m/s, low curvature <.0025/m, asphalt, dry, not braking; 28% drag/24% downforce reduction. No one-second racing rule is claimed. ERS (hold Space/Shift) supplies120kW from4MJ, braking recharges at up to55kW. Eight automatic ratios,6.4 final drive, RPM power curve/limiter. Four setup packages and four compounds influence forces; tire temp/wear is a simple bounded heat/wear approximation, not real compound fidelity. Wet grip shared with AI planning. Source/live telemetry is authoritative.

## Phase 4 sessions and rules
Weekend:90s practice →180s qualifying (best valid lap grid) →selected-lap race. Free practice remains unlimited. Grid positions derive from track geometry; jump starts disabled by locking grid, not falsely penalized. Three >1.2s track-limit excursions add5s; one5s pit-speed penalty per entry. Local yellow slows approaching AI; severe impact (>14m/s relative contact) triggers18s virtual safety-car neutralization at80km/h. AI passing disabled and follows predecessor; player VSC overspeed/overtake adds5s. No physical safety-car vehicle, red flag or comprehensive sporting code. Penalties alter final classification.
Real pit branch is an estimated5m-wide ribbon at offset−15m from the shared centerline, with tapered entry/exit, stationary boxes,80km/h limiter (L),2.8s service and actual compound/temperature/wear/repair reset. Press P to request, manually drive into box; AI steers/brakes to its own box through physics. Service cannot execute twice on one request. No fuel UI/model.

## Phase 5 environment
Shared global wetness evolves from rain/drying, supplied to every car and AI. Not per-sector puddles or aquaplaning. Four renderer modes have actual sky/fog/light changes; night uses nearby track-light pools (no race-car headlights), rain has capped particles/spray, wet material and blinking rear light. Aggregate wing damage from impacts over8m/s reduces total/front aero and visibly shrinks the front wing; no suspension/puncture/engine-damage claims. Pit service repairs it. Static kerbs/pit strips and car body components are merged by material; repeated rails/trees instanced.

## Phase 6 local data
Aero trim scales base downforce and drag; brake bias distributes real braking force. Applied next session and stored locally. Telemetry samples10Hz, max6000 per lap; truncated/invalid laps never saved as references. Record key includes circuit, physics version, package, compound, environment preset and trim. Eight recent configuration bests maximum; data schema/finite-number validation and storage-failure handling. Distance-aligned sampled delta, speed trace and actual sectors; no invented exact corner-loss analysis. Engineer priority rules explicitly cite measured damage, wetness, wear, temperature, energy or slip-angle thresholds; optional and offline.

## Phase 7 modes and input
Free practice, quick race, weekend, time trial, flying hot lap and three-round single-circuit championship. Central scoring25/18/15/12/10/8/6/4/2; no fastest-lap bonus. Result IDs prevent duplicate awards; ties resolved by counts of higher finishes then driverID. Teams pair consecutive driverIDs (last team singleton). Championship local save schema/version and bounded history. Best-lap ghost samples interpolate by lap time, render-only transparent model excluded from cars/collision.
Configurable keyboard mapping + arrow fallback, settings focus protection and conflict checks; standard gamepad adapter/adjustable deadzone and experimental touch pointer controls. Keyboard remains required fallback for untested devices. Color/contrast, HUD scale, volume/mute and reduced camera motion. No full replay or tilt support claimed.

## Release hardening
All source formatted and type-checked. Runtime option/storage validation; invalid physical state recovers before propagating NaNs. Lap attempts separate incomplete laps from completed records, prevent joined telemetry and require near-full unwrapped progress. Brake regeneration uses actual braking work (no stationary charging). Reverse limited to8m/s. Finished cars/penalties/timers freeze classification and use AI cooldown. Menu/session keyboard focus and blur/countdown pause; dialogs constrain Tab focus. WebGL context loss stops simulation with reload guidance.
Build manifest hashes final output bytes after Vite's write stage; source fingerprint covers source/public/lock/config/entry inputs. Runtime fetch compares embedded revision/fingerprint, explicitly reports unavailable/mismatched manifest, never claims remote synchronization. Production assets self-contained. No service worker/stale fallback bundle.
Static scenery batched with vertex colors, wheels use instancing; material/geometry/instance buffers disposed on replacement. Low uses diffuse-only Lambert shading and0.85 pixel ratio, no shadows, reduced lights/particles; higher settings retain standard materials. Software-rasterizer performance remains inadequate for a smooth-play claim; see measured results.
